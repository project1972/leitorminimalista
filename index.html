Ajuda da função

Aparar e organizar texto

🔗 Para juntar duas células: clique no botão 🔗 da primeira célula. Ele mescla essa célula diretamente com a próxima célula abaixo.
Nenhuma palavra selecionada
Clique numa palavra para selecioná-la. Com uma palavra selecionada, use ⬆️/⬇️ para transferi-la para a célula acima ou abaixo. Use + para nova célula, ↑↓ para reorganizar, ↵ para quebra de linha, 🔗 para mesclar com a próxima célula; × para excluir.
